# Исходный код платформы CyberBreak 2026

Каталог содержит полный исходный код бэкенда, фронтенда и скриптов запуска автономной платформы семантического поиска и анализа видеолекций.

---

## Содержимое каталога

- `backend/`: Серверная часть на базе FastAPI, SQLModel (SQLite), Faster-Whisper, FastEmbed (ONNX Runtime) и локальной LLM (Ollama).
- `frontend/`: Веб-интерфейс на React 18, TypeScript, Vite, Tailwind CSS и Framer Motion (Liquid Glass UI).
- `run.bat`: Скрипт быстрого запуска платформы для Windows в один клик.
- `run.ps1`: Скрипт запуска для PowerShell.
- `start.py`: Кроссплатформенный лаунчер Python с автоматической проверкой зависимостей и целостности медиафайлов.

---

## Запуск из этого каталога

### 1. Автоматический запуск
- В среде Windows: запустите `run.bat`
- В среде PowerShell: `.\run.ps1`
- В консоли Python: `python start.py`

После старта веб-интерфейс доступен по адресу: http://127.0.0.1:8000
