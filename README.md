# Киберрывок 2026: Семантический поиск и анализ видеолекций

---

## Ключевые возможности

### 1. 100% Автономная работа (Local-first & Privacy-first)
- Все нейросети (распознавание речи, построение векторных эмбеддингов, семантический поиск, генерация тестов и RAG-ответы) выполняются **локально на вашем оборудовании**.
- Никакие видео, аудио, транскрипты и персональные данные **не отправляются во внешние облака**.

### 2. Мультимедийный пайплайн и автоматические превью
- **Умное извлечение превью:** автоматическая генерация качественных постеров видеокадров через FFmpeg на ключевой точке лекции.
- **Потоковое видеовещание (HTTP 206 Partial Content):** мгновенная перемотка видеофайлов любого размера и разрешения без предварительной буферизации.
- **Поддержка любых источников:** загрузка локальных файлов (`.mp4`, `.webm`, `.mkv`, `.mov`) и автоматический импорт лекций по прямой ссылке через `yt-dlp`.

### 3. Высокоточная речевая аналитика и субтитры
- **Распознавание речи через Faster-Whisper:** аппаратное ускорение на NVIDIA GPU (CUDA Float16 / Int8) с бесшовным фоллбэком на оптимизированный CPU-инференс.
- **Двухуровневая индексация аудиоряда:**
  - *Микросегменты (3-7 секунд):* построчные синхронные субтитры и мгновенная подсветка активного фрагмента при воспроизведении.
  - *Скользящие макроокна (~35 секунд с перекрытием 10 секунд):* сохранение контекста мысли и высокоточный семантический поиск.

### 4. Векторный семантический поиск
- Поиск фрагментов лекции по смыслу запроса на естественном языке с использованием многоязычной модели `paraphrase-multilingual-MiniLM-L12-v2` (FastEmbed ONNX Runtime).
- Ранжирование через косинусное сходство векторов с фильтрацией по порогу релевантности.

### 5. Структурирование знаний и ИИ-артефакты
- **Аналитический конспект:** структурированный Markdown-конспект лекции с выделением ключевых тезисов, выводов и практических рекомендаций.
- **Интерактивное оглавление:** автоматическая разбивка лекции на смысловые главы с кликабельными таймкодами начала тем.
- **Глоссарий терминов:** извлечение ключевых терминов и концепций с их определениями и таймкодом первого упоминания в видео.
- **RAG-ассистент «Вопрос-ответ»:** локальный чат по содержанию лекции, приводящий строгие ответы и точные цитаты с таймкодами источников.

### 6. Интерактивная проверка знаний (AI-Квиз)
- Генерация тестирования из 3-5 вопросов с 4 вариантами ответа на базе содержания лекции.
- Мгновенная проверка ответов, подробные объяснения правильного варианта и прямая кнопка перехода к соответствующему фрагменту лекции `[MM:SS]`.
- Поддержка работы как через локальную Ollama (Qwen 2.5 / LLaMA), так и через встроенный эвристический генератор при отсутствии LLM.

### 7. Заметки и закладки на таймкодах
- Добавление персональных заметок с привязкой к точной секунде видео в один клик прямо под плеером (`+ Заметка [MM:SS]`).
- Интерактивная лента закладок на таймлайне видео с автоподсветкой активной заметки во время просмотра.
- Полноценное управление заметками (создание, редактирование на месте, удаление) и экспорт всех заметок лекции в Markdown-файл (`.md`).

### 8. Продуманный плеер и дизайн Liquid Glass
- **Современный UI:** полупрозрачный интерфейс в стиле Liquid Glass с плавной анимацией Framer Motion, поддержкой тёмной и светлой темы.
- **Управление просмотром:** регулировка скорости (0.75x-2.0x), автозапоминание позиции просмотра с баннером возобновления, режим «Картинка в картинке» (PiP), театральный режим и полноэкранный просмотр.
- **Горячие клавиши:** `Space` (Play/Pause), `←` / `→` (перемотка ±5 сек), `Ctrl/Cmd + K` или `/` (фокус на поиск).
- **Каталогизация:** категории с цветовой палитрой Apple Pro, фильтрация по избранному, поиск по названию и авторам, сортировка по дате и продолжительности.
- **Личный профиль:** безопасная локальная авторизация (PBKDF2 SHA-256), хранение сессий.

## Быстрый запуск

### Вариант 1: Запуск в 1 клик (Рекомендуемый)

Перейдите в каталог `1. Исходный код` и запустите лаунчер:

- **Windows:** дважды кликните по файлу `1. Исходный код/run.bat`
- **PowerShell:** `cd "1. Исходный код"; .\run.ps1`
- **Командная строка:** `cd "1. Исходный код"; python start.py`

Приложение откроется по адресу: **http://127.0.0.1:8000**  
Интерактивная документация Swagger: **http://127.0.0.1:8000/docs**

---

### Вариант 2: Ручной запуск сервера

1. **Установка зависимостей:**
   ```bash
   pip install -r backend/requirements.txt
   ```

2. **Запуск сервера FastAPI:**
   ```bash
   python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
   ```
   *Сервер автоматически раздает предсобранный фронтенд из папки `frontend/dist` без необходимости запуска Node.js.*

3. **(Опционально) Запуск фронтенда в режиме разработки (HMR):**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

---

### Вариант 3: Подключение локальной нейросети через Ollama

Платформа полностью функциональна «из коробки» благодаря встроенным эвристическим алгоритмам. Для максимального качества конспектов, квизов и RAG-ответов рекомендуется подключить Ollama:

1. Скачайте и установите [Ollama](https://ollama.ai).
2. Загрузите модель:
   ```bash
   ollama run qwen2.5:7b
   ```
3. Запустите платформу. Сервер автоматически обнаружит доступную модель, и в статус-баре загорится зеленый индикатор LLM.

## Основные API эндпоинты

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/lectures` | Список всех лекций с фильтрацией и категориями |
| `POST` | `/api/lectures/upload` | Загрузка локального видеофайла и запуск анализа |
| `POST` | `/api/lectures/import-url` | Импорт лекции по URL через yt-dlp |
| `GET` | `/api/lectures/{id}` | Детальная информация, субтитры, главы и глоссарий |
| `GET` | `/api/lectures/{id}/stream` | Потоковое вещание видео (HTTP Range 206) |
| `GET` | `/api/lectures/{id}/thumbnail` | Постер / превью лекции |
| `GET` | `/api/lectures/{id}/quiz` | Интерактивный тест для проверки знаний (`?regenerate=true`) |
| `GET` | `/api/lectures/{id}/notes` | Список заметок с таймкодами |
| `POST` | `/api/lectures/{id}/notes` | Создание заметки на таймкоде |
| `PUT` | `/api/lectures/{id}/notes/{note_id}` | Редактирование заметки |
| `DELETE` | `/api/lectures/{id}/notes/{note_id}` | Удаление заметки |
| `GET` | `/api/search?q={query}` | Векторный семантический поиск по лекциям |
| `POST` | `/api/lectures/{id}/ask` | RAG-чат «Вопрос-ответ» по содержанию лекции |
| `GET` | `/api/system/status` | Статус оборудования (GPU/CUDA, Whisper, Ollama) |
