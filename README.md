# Киберрывок 2026: Семантический поиск и анализ видеолекций

Автономная локальная система для семантического анализа учебных видеоматериалов, поиска по смыслу речи, синхронного конспектирования и навигации без использования внешних облачных сервисов.

## Ключевые возможности

- 100% автономная работа: все нейросети (распознавание речи, векторные эмбеддинги, поиск, LLM) работают локально на компьютере без отправки данных в облако.
- Распознавание речи: извлечение аудио и транскрибация через Faster-Whisper с автоматическим выбором CUDA GPU или CPU (int8).
- Семантический векторный поиск: поиск фрагментов лекции по смыслу запроса на естественном языке на базе модели MiniLM-L12-v2 (FastEmbed ONNX) и косинусного сходства NumPy.
- Двухуровневая индексация: микросегменты речи (3-7 секунд) для построчных субтитров и скользящие макроокна (~35 секунд с перекрытием 10 секунд) для точного поиска.
- Автоматический конспект и оглавление: генерация структурированного Markdown-конспекта, разбивка лекции на главы и глоссарий терминов с таймкодами первого упоминания.
- RAG-ассистент: ответы на вопросы по содержанию лекции с кликабельными таймкодами источников (через Ollama или встроенный офлайн-движок).
- Видеоплеер с поддержкой HTTP Range (206 Partial Content): мгновенная перемотка видеофайлов любого размера без предварительной буферизации.
- Режимы просмотра: выбор скорости (0.75x, 1x, 1.25x, 1.5x, 1.75x, 2x), запоминание позиции просмотра, театральный режим, картинка в картинке (PiP) и полноэкранный режим.
- Каталогизация и сортировка: организация лекций по категориям с цветовой палитрой Apple Pro, раздел избранного, сортировка по дате, названию и длительности.
- Личный профиль и безопасность: локальное хеширование паролей (PBKDF2 SHA-256), сессионные токены, поддержка тёмной и светлой темы оформления.

## Стек технологий

- Backend: Python 3.10+, FastAPI, SQLModel, SQLite, Uvicorn
- Речевая аналитика: Faster-Whisper, soundfile, FFmpeg, yt-dlp
- Векторный поиск: FastEmbed (ONNX Runtime), NumPy
- Локальная нейросеть: Ollama (Qwen 2.5 / LLaMA 3.2)
- Frontend: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion

## Запуск проекта

### 1. Автоматический запуск (в 1 клик)

Скрипт проверяет зависимости, поднимает сервер и автоматически открывает веб-интерфейс в браузере:

- Windows: запуск двойным кликом файла run.bat
- PowerShell: .\run.ps1
- Консоль Python: python start.py

Веб-интерфейс откроется по адресу: http://127.0.0.1:8000
Документация API Swagger: http://127.0.0.1:8000/docs

### 2. Ручной запуск

Установка зависимостей бэкенда:
```bash
pip install -r backend/requirements.txt
```

Запуск сервера (раздает REST API и предсобранный веб-интерфейс):
```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Для запуска фронтенда в режиме разработки (требуется Node.js):
```bash
cd frontend
npm install
npm run dev
```

### 3. Запуск с локальной языковой моделью через Ollama

Система работает автономно и без Ollama благодаря встроенному генератору. Для подключения большой языковой модели:

1. Установите и запустите Ollama (https://ollama.ai).
2. Загрузите модель командой:
```bash
ollama run qwen2.5:7b
```
3. Запустите платформу. Сервер автоматически определит запущенную модель, и в правом верхнем углу интерфейса отобразится статус подключения к LLM.
