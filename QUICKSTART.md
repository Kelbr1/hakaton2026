# 🚀 Быстрый запуск платформы (Quick Start Guide)

## Вариант 1: Запуск в 1 клик (Рекомендуемый)

Скрипт сам проверит библиотеки, доустановит недостающие, запустит сервер и откроет сайт в браузере:

* **Windows:** Дважды кликните по файлу **`run.bat`** (или в консоли: `run.bat`)
* **PowerShell:** `.\run.ps1`
* **Python (любая ОС):** `python start.py`

> 🌐 **Сайт откроется автоматически:**  
> - С режимом разработчика: **`http://localhost:5173`**  
> - В автономном режиме (без Node.js): **`http://127.0.0.1:8000`**  
> - Интерактивная документация Swagger API: **`http://127.0.0.1:8000/docs`**

## Вариант 2: Ручной пошаговый запуск

### 1. Бэкенд (Python)
1. Установите зависимости:
   ```bash
   pip install -r backend/requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
   ```

### 2. Фронтенд (React + Vite)
*(Требуется Node.js 18+)*
1. Перейдите в папку фронтенда и установите пакеты:
   ```bash
   cd frontend
   npm install
   ```
2. Запустите dev-сервер:
   ```bash
   npm run dev
   ```

## Вариант 3: Подключение локальной нейросети Ollama (Опционально)

Платформа **полностью автономна**: если нейросеть не запущена, автоматически включится встроенный алгоритмический движок конспектов.

Если вы хотите подключить большую языковую модель:
1. Скачайте и запустите **[Ollama](https://ollama.ai)**.
2. Загрузите модель командой:
   ```bash
   ollama run qwen2.5:7b
   ```
   *(или более легкую: `ollama run qwen2.5:3b`)*
3. При запуске платформы статус `LLM Online` загорится зелёным в правом верхнем углу шапки.
