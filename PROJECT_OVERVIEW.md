# 🎓 Платформа семантического анализа и каталогизации видеолекций «Киберрывок 2026»

> **Полный инженерный и архитектурный контекст проекта для анализа языковыми моделями (LLM Context Prompt).**  
> Этот документ содержит исчерпывающее описание предметной области, архитектуры, полного технологического стека, базы данных, алгоритмов, механик и интерфейсных решений системы.

---

## 1. Обзор проекта и решаемая задача

Проект представляет собой **автономную веб-платформу для интеллектуальной обработки, семантического анализа, каталогизации и интерактивного изучения видеолекций**. 

### Главная проблема, которую решает система:
Студенты и специалисты тратят часы на ручной просмотр длинных видеозаписей в поисках конкретного фрагмента или ответа на вопрос. Стандартный поиск по ключевым словам бессилен, если лектор формулирует мысль синонимами или объясняет концепцию другими словами.

### Решение:
Платформа берет видеофайл или ссылку на лекцию (YouTube, VK, RuTube и др.), локально извлекает аудиодорожку, переводит речь в текст с посекундной точностью, векторизует смысловые окна речи в 384-мерное эмбеддинг-пространство, структурирует конспект, разбивает лекцию на главы с таймкодами и выделяет глоссарий терминов. Пользователь может искать фрагменты **по смыслу** на естественном языке, кликать на таймкоды для мгновенного перехода в видеоплеере и изучать лекцию в премиальном интерфейсе «Жидкое стекло» (Liquid Glass).

### Ключевая особенность:
**100% автономная локальная работа (Zero Cloud Dependency)**. Все нейросети (распознавание речи, векторные эмбеддинги, локальная LLM) запускаются на компьютере пользователя без использования платных облачных API и без утечки персональных или учебных данных.

## 2. Полный технологический стек

| Слой / Подсистема | Технология / Библиотека | Назначение и причина выбора |
| :--- | :--- | :--- |
| **Backend Framework** | **Python 3.10+ / FastAPI** | Высокопроизводительный асинхронный ASGI-фреймворк. Нативная поддержка Pydantic v2 для строгой валидации схем, автогенерация Swagger OpenAPI документации. |
| **База данных & ORM** | **SQLite + SQLModel** | `SQLModel` объединяет Pydantic и SQLAlchemy: одна модель описывает и таблицу в БД, и схему API без дублирования кода. SQLite хранится в одном локальном файле `database.db`, не требует развертывания СУБД. |
| **Распознавание речи (ASR)** | **Faster-Whisper (`small`)** | Модель Whisper на базе CTranslate2. Работает в 4 раза быстрее оригинального Whisper, потребляет минимум памяти. Автоматически выбирает GPU (CUDA float16) либо процессор (CPU int8). |
| **Аудиопроцессинг** | **FFmpeg, soundfile, wave** | Извлечение аудиодорожки, нормализация звука, конвертация в 16 kHz Mono WAV для Whisper. Патч совместимости PyAV 14+. |
| **Скачивание видео** | **yt-dlp** | Универсальный загрузчик видео и аудио с более чем 1000 платформ (YouTube, RuTube, VK Видео, прямые ссылки на CDN). |
| **Векторный поиск** | **FastEmbed (ONNX Runtime) & Sentence-Transformers** | Модель `paraphrase-multilingual-MiniLM-L12-v2` (384-мерные эмбеддинги). FastEmbed работает на легковесном ONNX Runtime без необходимости ставить многогигабайтный PyTorch. Векторный поиск реализован на матричной математике косинусного сходства NumPy. |
| **Генеративный ИИ (LLM)** | **Ollama REST API (`qwen2.5:7b`, `qwen2.5:3b`, `llama3.2`)** | Локальный вывод открытых LLM через REST API (`http://localhost:11434`). Модель Qwen 2.5 идеально структурирует конспекты и термины на русском языке. |
| **Отказоустойчивый fallback** | **Алгоритмический NLP-движок (`_algorithmic_fallback_summary`)** | Работает при выключенной Ollama. Алгоритмически делит лекцию на главы по временным квантам, проводит частотный анализ (TF-IDF эвристика со стоп-словами) и стемминг корней слов (`russian_stem`) для точной привязки терминов к секундам видео. |
| **Потоковое видеовещание** | **HTTP Range Requests (206 Partial Content)** | Реализовано нативное чтение байтовых интервалов из файла с отдачей заголовков `Content-Range` и `Accept-Ranges: bytes`. Позволяет мгновенно перематывать многогигабайтные видеофайлы без буферизации всего видео. |

## 4. Ключевые алгоритмы и механики

### 4.1. Двухуровневая индексация транскрипта (Micro & Macro)
Обычное разбиение текста на абзацы плохо подходит для видео: фразы лектора могут длиться несколько секунд, а мысль — минуту. В платформе реализована двухуровневая модель:
1. **`TranscriptSegment` (микро-уровень, 3–7 секунд)**:
   - Создаётся моделью Faster-Whisper.
   - Хранит точные секунды начала (`start_time`) и конца (`end_time`).
   - Используется на фронтенде для **построчного синхронного отображения субтитров**, автоматической прокрутки вслед за видео и клика по любой фразе для перемотки плеера.
2. **`SearchChunk` (макро-уровень, 30–45 секунд со скользящим окном)**:
   - Формируется объединением соседних сегментов речи в более крупные смысловые блоки с **перекрытием в 10 секунд** (sliding window).
   - Для каждого чанка генерируется 384-мерный нормализованный вектор через FastEmbed.
   - Перекрытие в 10 секунд гарантирует, что мысль лектора, находящаяся на стыке двух фрагментов, не потеряет контекст при поиске.

### 4.2. Семантический векторный поиск по смыслу
- Пользователь вводит запрос на естественном языке (например: *"как работает внимание в трансформерах"*).
- Запрос векторизуется через FastEmbed в 384-мерный вектор $Q$.
- В памяти вычисляется косинусное сходство между $Q$ и матрицей векторов чанков $D$:
  $$\text{Cosine Similarity} = \frac{Q \cdot D}{\|Q\| \|D\|}$$
- Результаты фильтруются по порогу релевантности и сортируются по убыванию.
- Фронтенд выводит карточки найденных мест с процентом смыслового соответствия (например, `89.4% по смыслу`) и таймкодом. Нажатие на кнопку мгновенно переносит плеер на найденный фрагмент.
- Поиск доступен как **глобально** по всей библиотеке лекций с главного экрана (Spotlight-поиск), так и **локально** внутри конкретной открытой лекции.

### 4.3. Пайплайн обработки видео (4 фазы)
Обработка видео выполняется асинхронно в фоновом потоке, с обновлением статуса в БД:
1. **Фаза 1: Загрузка и конвертация (`downloading` / `processing`)**:
   - Если указан URL: `yt-dlp` скачивает аудио/видео.
   - Если загружен файл: сохраняется в папку `storage/`.
   - FFmpeg извлекает оптимизированную аудиодорожку (16 kHz, моно).
2. **Фаза 2: Речевая аналитика (`transcribing`)**:
   - `Faster-Whisper` генерирует сегменты речи с таймкодами.
3. **Фаза 3: Векторизация и чанкинг (`indexing`)**:
   - Формирование скользящих макро-окон, генерация эмбеддингов, запись в таблицу `searchchunk`.
4. **Фаза 4: Синтез артефактов (`generating` $\rightarrow$ `ready`)**:
   - Если Ollama онлайн: запрос к Qwen 2.5 с генерацией структурированного JSON (конспект Markdown, главы с таймкодами, глоссарий).
   - Если Ollama оффлайн: алгоритмический фоллбэк с частотным анализом терминов и временным квантованием глав.

### 4.4. Стриминг видео с поддержкой HTTP Range (206 Partial Content)
Эндпоинт `/api/lectures/{id}/stream` парсит заголовок `Range: bytes=start-end`:
- Считывает ровно запрошенный диапазон байт с диска без загрузки всего 2-гигабайтного файла в RAM.
- Возвращает статус `HTTP 206 Partial Content` с заголовком `Content-Range: bytes start-end/total`.
- Это обеспечивает **мгновенную перемотку видео** в браузере в любую точку без зависания.

## 5. Дизайн-система «Жидкое стекло» (Liquid Glass)

Интерфейс спроектирован по канонам Apple VisionOS, macOS Sonoma и Linear:

1. **Многослойное матовое стекло (Frosted Glass)**:
   - Классы `.liquid-glass`, `.liquid-glass-nav`, `.liquid-glass-card`, `.liquid-glass-modal`.
   - Размытие фона: `backdrop-filter: blur(28px) saturate(180%)`.
   - Светлая тема: молочно-белая полупрозрачная основа (`rgba(255, 255, 255, 0.75)`), контрастные сланцевые обводки (`rgba(148, 163, 184, 0.35)`), предотвращающие размывание на светлом фоне.
   - Тёмная тема: глубокий обсидиановый полупрозрачный фон (`rgba(11, 14, 26, 0.62)`) с микро-обводками `rgba(255, 255, 255, 0.12)` и верхним световым бликом `inset 0 1px 1px rgba(255, 255, 255, 0.2)`.

2. **Кинематографичное круговое переключение темы (View Transitions API)**:
   - При нажатии на кнопку темы фиксируются точные координаты клика $(X, Y)$.
   - С тёмной на светлую тему: круг света расширяется (`clip-path: circle(0px)` $\rightarrow$ `circle(maxRadius)`), исходя из кнопки по всему экрану.
   - Со светлой на тёмную тему: тёмный круг сжимается обратно в кнопку переключения.

3. **Кастомные Liquid Glass всплывающие подсказки ([`Tooltip.tsx`](file:///d:/hakatonfinal%20—%20копия/frontend/src/components/Tooltip.tsx))**:
   - Полная замена стандартных браузерных подсказок `title="..."`.
   - Рендеринг через `createPortal` прямо в корень страницы с `fixed z-[999999]`: подсказки **никогда не обрезаются** родительскими контейнерами с `overflow: hidden`.
   - Авто-флип (разворачивается вниз, если упирается в верхний край экрана) и горизонтальный клампинг.
   - Дебаунс появления 180 мс и мгновенное скрытие при клике или скролле.

4. **Интерактивный стеклянный блик за курсором (Cursor Glass Spotlight)**:
   - При движении мыши по карточкам лекций на главном экране по стеклу скользит мягкий радиальный блик.
   - Работает на частоте 120 FPS: координаты передаются напрямую в CSS-переменные `--mouse-x` и `--mouse-y` через GPU-композитор без вызова `setState` в React.

5. **Плеер с расширенным управлением**:
   - Выбор скорости воспроизведения: `0.75x`, `1x`, `1.25x`, `1.5x`, `1.75x`, `2x`.
   - Театральный режим (расширение видео на 6 колонок сетки) и режим «Картинка в картинке» (Picture-in-Picture).
   - Запоминание прогресса просмотра в `localStorage` с всплывающим баннером «Продолжить с 04:15?».
   - Горячие клавиши: `Space` (пауза/воспроизведение), `← / →` (перемотка на 5 секунд), `Ctrl+K` или `/` (быстрый переход к поиску).

## 6. Сущности базы данных (SQLModel / SQLite)

1. **`User`**: пользователь платформы (id, email, full_name, password_hash PBKDF2 SHA-256, avatar_color, created_at).
2. **`UserSessionToken`**: сессионные токены авторизации (id, user_id, token, created_at).
3. **`Category`**: тематические категории лекций с цветом из палитры Apple Pro (id, name, color, created_at).
4. **`UserFavorite`**: связь «многие ко многим» для избранных лекций пользователя (id, user_id, lecture_id, created_at).
5. **`Lecture`**: главная сущность видеолекции (id, title, source_type ['file'|'url'], source_url, video_path, audio_path, duration, status ['uploading'|'processing'|'transcribing'|'indexing'|'generating'|'ready'|'error'], error_message, summary_markdown, category_id, created_at).
6. **`TranscriptSegment`**: субтитры (id, lecture_id, start_time, end_time, text).
7. **`SearchChunk`**: поисковые смысловые блоки (id, lecture_id, start_time, end_time, text, embedding_json [384 float]).
8. **`LectureChapter`**: главы лекции с таймкодами (id, lecture_id, title, start_time, summary).
9. **`GlossaryTerm`**: термины и определения (id, lecture_id, term, definition, first_timecode).

Платформа спроектирована для мгновенного развертывания на любом компьютере:

1. **Запуск в 1 клик (Windows / Linux / macOS)**:
   - Запустить файл `run.bat` (двойным кликом в Windows) или `./run.ps1` в PowerShell.
   - Скрипт проверит окружение, поднимет backend-сервер, который раздаёт и REST API, и скомпилированный фронтенд по адресу: **`http://127.0.0.1:8000`**, и автоматически откроет страницу в браузере.
2. **Подключение локальной LLM (опционально)**:
   - Установить [Ollama](https://ollama.ai) и выполнить: `ollama run qwen2.5:7b`.
   - Платформа мгновенно подхватит запущенную модель (статус отобразится в шапке). Если Ollama не запущена, автоматически активируется встроенный алгоритмический генератор конспектов.
3. **Автотесты**:
   - `python -m backend.test_stage1` — тест извлечения аудио и транскрибации Whisper.
   - `python -m backend.test_stage2` — тест векторизации FastEmbed, косинусного поиска и генератора артефактов.
   - `python -m backend.test_stage3` — тест авторизации, сессий и категорий.
