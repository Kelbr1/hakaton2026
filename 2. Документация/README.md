# Документация проекта CyberBreak 2026

Комплект технической и эксплуатационной документации автономной платформы семантического поиска и интеллектуального анализа видеолекций.

---

## Структура документации

1. [01_АРХИТЕКТУРА_СИСТЕМЫ.md](./01_АРХИТЕКТУРА_СИСТЕМЫ.md)
   Общее архитектурное устройство системы, модули бэкенда и фронтенда, схема потоков данных, организация базы данных SQLModel и потоковое вещание по протоколу HTTP 206 Partial Content.

2. [02_АЛГОРИТМЫ_И_AI_МОДЕЛИ.md](./02_АЛГОРИТМЫ_И_AI_МОДЕЛИ.md)
   Подробное описание используемых нейросетевых моделей (Faster-Whisper, MiniLM-L12-v2 FastEmbed, Ollama), алгоритма двухуровневой сегментации, векторного поиска на базе косинусного сходства, генерации конспектов, квизов и RAG-ответов.

3. [03_API_СПЕЦИФИКАЦИЯ.md](./03_API_СПЕЦИФИКАЦИЯ.md)
   Полный справочник REST API: сигнатуры запросов, схемы входных и выходных параметров, HTTP-коды ответов для лекций, поиска, заметок, квизов, категорий и авторизации.

4. [04_ПОЛЬЗОВАТЕЛЬСКАЯ_ИНСТРУКЦИЯ.md](./04_ПОЛЬЗОВАТЕЛЬСКАЯ_ИНСТРУКЦИЯ.md)
   Пошаговое руководство пользователя по работе с платформой: добавление лекций, управление плеером, работа с конспектом, прохождение интерактивных тестов, создание заметок на таймкодах и поиск.

5. [05_БЕЗОПАСНОСТЬ_И_ОТКАЗОУСТОЙЧИВОСТЬ.md](./05_БЕЗОПАСНОСТЬ_И_ОТКАЗОУСТОЙЧИВОСТЬ.md)
   Принципы локальной безопасности данных, защита учетных записей, алгоритмы автоматического переключения при отсутствии GPU или Ollama.
