# Спецификация REST API CyberBreak 2026

Документ содержит описание всех HTTP-эндпоинтов серверной части платформы.

Базовый URL: `http://127.0.0.1:8000`  
Формат данных: `application/json` (если не указано иное)

---

## 1. Управление лекциями

### 1.1. Получение списка лекций
- **Метод:** `GET`
- **Путь:** `/api/lectures`
- **Параметры запроса (Query):**
  - `category_id` (int, опционально): фильтрация по идентификатору категории;
  - `favorites_only` (bool, опционально): фильтрация только по избранным лекциям;
  - `search` (str, опционально): текстовый поиск по названию лекции;
  - `sort_by` (str, по умолчанию "created_at"): поле сортировки ("created_at", "title", "duration");
  - `sort_order` (str, по умолчанию "desc"): направление сортировки ("asc", "desc").
- **Код ответа:** `200 OK`
- **Тело ответа:** Массив объектов `LectureResponse`.

### 1.2. Загрузка видеофайла
- **Метод:** `POST`
- **Путь:** `/api/lectures/upload`
- **Тип содержимого:** `multipart/form-data`
- **Параметры формы:**
  - `file` (файл): бинарный файл видео (.mp4, .webm, .mkv, .mov);
  - `title` (str, опционально): пользовательское название лекции;
  - `category_id` (int, опционально): идентификатор категории.
- **Код ответа:** `201 Created`
- **Тело ответа:** Объект созданной лекции `LectureResponse` со статусом `processing`.

### 1.3. Импорт лекции по URL
- **Метод:** `POST`
- **Путь:** `/api/lectures/import-url`
- **Тело запроса:**
  ```json
  {
    "url": "https://example.com/lecture.mp4",
    "title": "Введение в нейросети",
    "category_id": 1
  }
  ```
- **Код ответа:** `201 Created`
- **Тело ответа:** Объект `LectureResponse`.

### 1.4. Детальные данные лекции
- **Метод:** `GET`
- **Путь:** `/api/lectures/{id}`
- **Код ответа:** `200 OK` (или `404 Not Found`)
- **Тело ответа:** Объект `LectureDetailResponse`, включающий:
  - Основные метаданные лекции;
  - `segments`: массив микросегментов субтитров с полями `id`, `start_time`, `end_time`, `text`;
  - `chapters`: массив глав оглавления с полями `id`, `start_time`, `title`, `description`;
  - `glossary_terms`: массив терминов с полями `id`, `term`, `definition`, `timecode`;
  - `summary`: аналитический Markdown-конспект;
  - `category`: объект привязанной категории.

### 1.5. Обновление метаданных лекции
- **Метод:** `PATCH`
- **Путь:** `/api/lectures/{id}`
- **Тело запроса:**
  ```json
  {
    "title": "Новое название лекции",
    "category_id": 2
  }
  ```
- **Код ответа:** `200 OK`

### 1.6. Удаление лекции
- **Метод:** `DELETE`
- **Путь:** `/api/lectures/{id}`
- **Код ответа:** `200 OK`
- **Действие:** удаление записи лекции из базы данных со всеми зависимыми таблицами (сегменты, эмбеддинги, главы, термины, заметки, квизы) и удаление физических медиафайлов с диска.

### 1.7. Повторный запуск обработки (Retry)
- **Метод:** `POST`
- **Путь:** `/api/lectures/{id}/retry`
- **Код ответа:** `200 OK`

## 2. Потоковое видео и превью

### 2.1. Потоковое вещание видео (HTTP 206)
- **Метод:** `GET`
- **Путь:** `/api/lectures/{id}/stream`
- **Заголовки запроса:** `Range: bytes={start}-{end}` (опционально)
- **Код ответа:** `206 Partial Content` (при наличии Range) или `200 OK` (полный файл)
- **Заголовки ответа:**
  - `Content-Range: bytes {start}-{end}/{total}`
  - `Accept-Ranges: bytes`
  - `Content-Length: {chunk_size}`
  - `Content-Type: video/mp4`

### 2.2. Постер / Превью видео
- **Метод:** `GET`
- **Путь:** `/api/lectures/{id}/thumbnail`
- **Код ответа:** `200 OK` (или `404 Not Found`)
- **Тип содержимого:** `image/jpeg`

## 3. Семантический поиск и RAG-чат

### 3.1. Векторный семантический поиск
- **Метод:** `GET`
- **Путь:** `/api/search`
- **Параметры запроса (Query):**
  - `q` (str, обязательно): поисковый запрос на естественном языке;
  - `lecture_id` (int, опционально): ограничить поиск рамками одной лекции;
  - `limit` (int, по умолчанию 10): максимальное количество результатов.
- **Код ответа:** `200 OK`
- **Тело ответа:** Массив объектов `SearchResultItem`:
  ```json
  [
    {
      "chunk_id": 12,
      "lecture_id": 1,
      "lecture_title": "Основы глубокого обучения",
      "start_time": 245.5,
      "end_time": 281.0,
      "text": "Для оптимизации весов модели применяется метод обратного распространения ошибки...",
      "score": 0.841
    }
  ]
  ```

### 3.2. RAG-чат «Вопрос-ответ» по лекции
- **Метод:** `POST`
- **Путь:** `/api/lectures/{id}/ask`
- **Тело запроса:**
  ```json
  {
    "question": "В чем разница между градиентным спуском и Adam?"
  }
  ```
- **Код ответа:** `200 OK`
- **Тело ответа:**
  ```json
  {
    "answer": "В лекции лектор объясняет, что классический градиентный спуск использует постоянную скорость обучения, тогда как Adam вычисляет индивидуальные адаптивные скорости...",
    "sources": [
      {
        "timecode": 412.0,
        "text": "Фрагмент лекции с цитатой...",
        "score": 0.812
      }
    ]
  }
  ```

## 5. Заметки на таймкодах

### 5.1. Список заметок к лекции
- **Метод:** `GET`
- **Путь:** `/api/lectures/{id}/notes`
- **Код ответа:** `200 OK`
- **Тело ответа:** Массив объектов `LectureNoteResponse`, отсортированных по возрастанию `timecode`.

### 5.2. Создание заметки
- **Метод:** `POST`
- **Путь:** `/api/lectures/{id}/notes`
- **Тело запроса:**
  ```json
  {
    "timecode": 142.5,
    "text": "Рассмотреть подробнее формулу на слайде"
  }
  ```
- **Код ответа:** `201 Created`
- **Тело ответа:** Созданный объект `LectureNoteResponse`.

### 5.3. Редактирование заметки
- **Метод:** `PUT`
- **Путь:** `/api/lectures/{id}/notes/{note_id}`
- **Тело запроса:**
  ```json
  {
    "text": "Обновленный текст заметки"
  }
  ```
- **Код ответа:** `200 OK`

### 5.4. Удаление заметки
- **Метод:** `DELETE`
- **Путь:** `/api/lectures/{id}/notes/{note_id}`
- **Код ответа:** `200 OK`
- **Тело ответа:** `{"success": true, "id": {note_id}}`

## 6. Категории лекций

- `GET /api/categories`: получить список всех категорий с количеством привязанных лекций.
- `POST /api/categories`: создать категорию (`name`, `color`).
- `PUT /api/categories/{id}`: обновить название и цвет категории.
- `DELETE /api/categories/{id}`: удалить категорию (привязанные лекции переводятся в статус «Без категории»).

---

## 7. Авторизация и профиль пользователя

- `POST /api/auth/register`: регистрация (`username`, `password`, `full_name`).
- `POST /api/auth/login`: вход в систему, получение токена сессии.
- `POST /api/auth/logout`: аннулирование текущего сессионного токена.
- `GET /api/auth/me`: получение профиля авторизованного пользователя.
- `POST /api/lectures/{id}/favorite`: переключение статуса «В избранном».
